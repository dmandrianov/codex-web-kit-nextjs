# Закрытые условия использования Web Kit

Copyright © 2026 dmandrianov. Все права защищены.

Web Kit является закрытым коммерческим продуктом и не распространяется как open-source software. Эти условия применяются к каждой версии Web Kit, полученной по действующей подписке, если отдельный письменный договор не устанавливает иное.

## Что разрешено подписчику

Пока подписка активна, подписчик может:

- получать версии Web Kit из закрытого официального репозитория;
- использовать и изменять полученные версии в собственных проектах и проектах своих клиентов;
- хранить рабочие копии, необходимые для таких проектов;
- передавать клиенту готовый проект, в который встроены или для которого адаптированы части Web Kit.

Передача готового проекта не даёт клиенту или участнику команды отдельного права извлекать Web Kit, использовать его как самостоятельную базу, получать обновления или распространять его дальше.

## После окончания подписки

После отмены или окончания подписки прекращается доступ к закрытому репозиторию, новым релизам, обновлениям и услугам, входящим в подписку.

Версии, которые подписчик законно скачал во время активной подписки, можно продолжать использовать и изменять в собственных и клиентских проектах. Право не распространяется на версии, опубликованные после окончания подписки. Продолжение использования допускается только при соблюдении этих условий.

## Что запрещено

Без отдельного письменного разрешения нельзя:

- публиковать, зеркалировать, передавать, продавать, сдавать в аренду или сублицензировать Web Kit как самостоятельный продукт;
- распространять release-архивы, исходную базу целиком или её существенную часть в виде повторно используемого kit, шаблона или библиотеки;
- делиться учётной записью GitHub, приглашением, токеном, ключом, локальными данными авторизации или другим способом доступа к закрытым релизам;
- передавать архивы обновления, контрольные суммы или updater-пакеты, чтобы предоставить обновления человеку без действующей подписки;
- обходить ограничения доступа или создавать публичный либо закрытый mirror для третьих лиц;
- выдавать Web Kit или его исходную базу за собственный самостоятельный продукт.

Сама ссылка на repository или release технически не даёт права доступа или использования, но без отдельного письменного разрешения нельзя публиковать или передавать третьим лицам точный URL закрытого repository/release, приглашение либо другие сведения, раскрывающие закрытый источник. Особенно запрещено делать это для обхода подписки или помощи другому человеку в получении неразрешённого доступа.

Payment email используется для учёта оплаты и связи с подписчиком. Фактической границей доступа является отдельно подтверждённый GitHub username: приглашение выдаётся только этой учётной записи и не переносится на другой аккаунт автоматически.

## Работа команды и клиента

Участники команды и подрядчики могут работать с Web Kit только в пределах конкретного проекта подписчика или его клиента. Подписчик отвечает за то, чтобы они не получали отдельный канал обновлений и не переносили Web Kit в другие проекты как самостоятельную базу.

## Доступ и прекращение доступа

Владелец Web Kit может закрыть доступ к репозиторию и будущим релизам после окончания подписки или при нарушении этих условий. Техническое прекращение доступа не удаляет уже скачанные копии; правила их дальнейшего использования описаны выше.

## Отсутствие гарантий

Web Kit предоставляется «как есть». В максимально допустимой законом степени владелец не гарантирует непрерывную доступность репозитория, отсутствие ошибок или пригодность для конкретной цели и не отвечает за косвенные убытки, возникшие из-за использования продукта.

## Применимая версия условий

К скачанной версии Web Kit прилагается копия этого файла. Более новые условия регулируют будущие загрузки и обновления, если подписчик отдельно не согласился с их применением к ранее полученной версии.
