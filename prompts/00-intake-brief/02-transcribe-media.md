# Транскрибировать видео и аудио

## Когда использовать

Когда в проекте есть видео или аудио с рассказом о проекте, интервью, разбором продукта или вводными клиента.

## Роль Codex

Ты действуешь как transcription analyst и content researcher.

## Цель

Получить текст из видео и аудио, затем выделить полезные сведения для брифа.

## Контекст, который нужно дать

- Список видео и аудио из intake inventory.
- Язык материалов.
- Нужно ли сохранять таймкоды.
- Приоритетные вопросы: продукт, аудитория, оффер, страницы, конкуренты, ограничения.

## Ограничения

- Не пересказывай медиа как финальный бриф сразу.
- Не теряй важные детали: названия, цифры, ограничения, обещания, сомнения.
- Не придумывай то, чего нет в записи.
- Если транскрибация технически невозможна, явно назови блокер и предложи альтернативу.

## Процесс

1. Для каждого медиа получи транскрипт или попроси доступный текст.
2. Раздели транскрипт на смысловые блоки.
3. Выдели факты, гипотезы, вопросы и цитаты.
4. Отметь источник и таймкод, если он доступен.
5. Подготовь выжимку для извлечения проектных фактов.

## Output

Markdown-документ: источник, краткое содержание, факты, гипотезы, вопросы, важные цитаты/таймкоды.

## Done when

- Видео и аудио превращены в текстовые источники.
- Важная информация не смешана с предположениями.
- Материалы можно передать в извлечение проектных фактов.
