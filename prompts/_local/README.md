# Local Prompts

Put project-specific or user-specific prompt experiments here.

This folder is project-owned. Prompt Kit updates must not delete or overwrite it.

Recommended use:

- custom prompts for one project;
- temporary experiments;
- team-specific rules that are not ready for the shared kit.

If a local prompt becomes generally useful, copy it into the source Prompt Kit repository and release it through a normal version update.
