# Web Kit v0.9.0

This transition release reconnects Prompt Kit to the same GitHub repository after its transfer and rename to `dmandrianov/codex-web-kit-nextjs`.

## What changed

- The numeric repository trust anchor remains `1302994489`.
- The bundled updater now bootstraps from the new personal repository.
- Remote verification requires the canonical personal owner `dmandrianov` and accepts either valid boolean visibility after trust checks; release publication requires the repository to be public.
- Release publication preflight requires the transferred public personal repository.
- The legacy transport marker remains only as a compatibility bridge for the updater shipped in `0.8.0`.
- The repository and release package are licensed under MIT.
- Root `LICENSE` is copied to `.prompt-kit/TERMS.md` in the package only to satisfy the legacy updater path contract.

## Existing installations

The `0.8.0` updater cannot download this release remotely because it rejects a personal repository owner before release discovery. Verify and apply the `0.9.0` archive locally with explicit confirmation, as documented in `MIGRATIONS.md`. The repository ID does not change, project Git is untouched and all normal conflict, backup and rollback checks remain active.
