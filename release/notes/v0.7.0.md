# Web Kit v0.7.0 — три полноценных режима gpt-taste

Эта версия подключает оригинальный `gpt-taste` как отдельный visual creator engine без переписывания или сокращения upstream-скилла.

## Три режима

- `page` создаёт полноценный disposable page concept и сохраняет page-level характер оригинального skill.
- `block` создаёт одну выразительную marketing/editorial секцию внутри утверждённого сайта.
- `component` создаёт один самостоятельный expressive marketing component и specimen с нужными состояниями.

Во всех режимах Codex читает original `SKILL.md` полностью. Рамка режима ограничивает только результат: block/component не дорисовывают фиктивную страницу, Nav, Hero, Footer, новый оффер или неподтверждённый CTA.

Standalone component не требует page planning: короткий component spec фиксирует content/actions, реальные states, specimen и runtime scope. Если это первый gpt-taste артефакт проекта, его continuity profile остаётся candidate до явного user approval.

## Как выбирается engine

Style hypothesis и block spec явно записывают `Creator engine: native / gpt-taste`. Поэтому скилл вызывается автоматически в правильном этапе, но не срабатывает по случайному совпадению текста.

`gpt-taste` подходит для expressive marketing, campaign, editorial, portfolio и showcase UI. Dashboard, checkout, forms, data/business UI, локальные исправления, quality, SEO, deployment и maintenance остаются на стандартных маршрутах, если пользователь явно не попросил иначе.

## Как сохраняется качество между блоками

После утверждённого gpt-taste page concept проект получает continuity profile:

- locked typography/color/surface/action semantics и project seed;
- motion family и reduced-motion alternative;
- использованные и доступные layout/component/motion architectures;
- open choices, которые можно рандомизировать в следующем блоке или компоненте;
- approved visual evidence и asset truth.

Это сохраняет узнаваемость сайта, но не превращает каждый новый блок в копию Hero.

## Кто исправляет результат

Prompt Kit проверяет факты, доступность, безопасность, runtime и правильную адаптивную геометрию первого кадра. Визуальные замечания по композиции, типографике, ритму, поверхности, media treatment или motion возвращаются самому `$gpt-taste`, чтобы base workflow не разбавлял его дизайн.

## Для существующих проектов

Автоматический redesign не нужен. Новые режимы начинают работать со следующей подходящей визуальной задачи. Если существующий concept действительно был создан и утверждён через gpt-taste, continuity profile можно восстановить только из подтверждённых live/screenshots/decisions, не из догадок.
